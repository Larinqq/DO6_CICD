# Basic CI/CD

## О проекте

Проект направлен на освоение основ **непрерывной интеграции (CI)** и **непрерывной доставки (CD)** с использованием **GitLab CI/CD**. В рамках работы необходимо настроить автоматический пайплайн для сборки, тестирования и развертывания приложений из проекта SimpleBashUtils (утилиты `cat` и `grep`).

---

## Что нужно было сделать

### 1. Настройка инфраструктуры
- Поднять две виртуальные машины на **Ubuntu Server 24.04 LTS**
- Установить и зарегистрировать **gitlab-runner** для проекта

### 2. CI (Continuous Integration)
- **Сборка** — написать этап для сборки приложений через Makefile, сохранить артефакты на 30 дней
- **Кодстайл** — добавить проверку через `clang-format`, при ошибке пайплайн падает
- **Интеграционные тесты** — запускать тесты автоматически после успешной сборки и линтинга, при провале пайплайн падает

### 3. CD (Continuous Delivery)
- Поднять вторую виртуальную машину (продакшн)
- Написать bash-скрипт для копирования артефактов через `scp` в `/usr/local/bin`
- Добавить этап деплоя, запускаемый **вручную** после успешного CI

### 4. Дополнительно (опционально)
- Настроить Telegram-бота для уведомлений о результате пайплайна

---

## Результат

- Разработан полноценный CI/CD пайплайн в `.gitlab-ci.yml`
- Выполнена сборка, проверка кодстайла и интеграционное тестирование
- Настроен автоматический деплой на продакшн-сервер
- Сохранены дампы виртуальных машин (не в git)
